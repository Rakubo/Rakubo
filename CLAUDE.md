# Rakubo/Rakubo — GitHub profile repository

This is a special GitHub repository: its `README.md` is shown on the
profile page at https://github.com/Rakubo. It is **not** a project repo.

## What belongs here
- `README.md` (the profile page) and assets it references (e.g. images).
- This `CLAUDE.md`.

## What does NOT belong here
- Project code, notebooks, datasets, experiments, or notes for any project.

Each project gets its own repository under the `Rakubo` account
(e.g. `Rakubo/<project-name>`). If a task is project work and no matching
repository exists, stop and ask which repository it should go in (or
whether to create a new one) instead of committing it here.
